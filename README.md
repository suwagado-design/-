# 変わらない男

6枚の写真から、ある男の一生を振り返る約1分45秒の映像です。

▶ **[life_retrospective.mp4](life_retrospective.mp4)**（1920×1080 / 30fps / 音声つき）

## 予告編

▶ **[trailer.mp4](trailer.mp4)**（約1分30秒・シネスコ2.39:1・音声つき）

本編をもとに話をふくらませた、架空映画『変わらない男』の予告編です。

- **取調べ** —「生年月日は？」「大正七年、四月一日です。」
- **その男は、百八年間、一度も歳をとらなかった。** — 時計が逆回りして 2026 → 1936 へ巻き戻る
- **百年の記憶** — 学者を夢見た1936年、母の「長生き、するんだよ。」、戦地、上野駅での「ちっとも変わらないねえ。」、昭和の下町
- **2026** — 身元照合システム：戸籍上の年齢「108歳」、外見からの推定「20代前半」、判定「不一致」
- **クライマックス** — 百八年分の記憶が太鼓に合わせて次々に映り、「母さん。……長生き、しすぎたかな。」
- **タイトル** —「時代は変わる。男は、変わらない。」2027年 春 全国ロードショー（架空）
- **おまけ** —「……で、若さの秘訣は？」「早寝、早起きです。」

配給会社「百年映画」、映画評「月刊 空想シネマ」、公開日などもすべて架空のものです。

## 作り直す

```sh
# 必要: python3, numpy, scipy, Pillow, ffmpeg (libx264), 日本語明朝フォント (Noto Serif CJK JP か IPA明朝)
python3 make_video.py            # life_retrospective.mp4 を書き出す
python3 make_video.py --stills   # レイアウト確認用の静止画を build/stills/ に書き出す
python3 make_trailer.py          # trailer.mp4 を書き出す（make_video.py の部品を使う）
python3 make_trailer.py --stills # 予告編の確認用静止画を build/trailer_stills/ に書き出す
```

- 映像は Pillow + numpy で1フレームずつ描画しています（ゆっくりズームするケン・バーンズ効果、フィルムグレイン、ちらつき、クロスフェード、爆発の閃光と揺れ）。
- 音楽と効果音（ピアノ、ドローン、小太鼓、爆発音、汽笛、雑踏、鉄扉、おりん）はすべてコードで合成しており、外部の音源は使っていません。
- セリフや年代、章の長さは `make_video.py` の `SCENES` で変えられます。
